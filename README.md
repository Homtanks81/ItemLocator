# ItemLocator

A lightweight World of Warcraft addon for Vanilla and Mysteries of Azeroth expansion that tracks items in your bag, bank, mailbox or in transit.

## Features
* **Tooltip Display** - On mouseover of any item will display its location across any characters on your account.

## Installation
1. Go to the **Releases** tab on the right side of this GitHub page.
2. Download the latest `ItemLocator.zip` file.
3. Extract the contents of the `.zip` file into your WoW Interface AddOns folder:
   * **Vanilla/MoA:** `World of Warcraft\Interface\AddOns\`
4. Make sure the extracted folder name matches the name inside the `.zip` exactly.

## How to Use
* Open any location items on your character are located to populate the addon directory: Bags, Bank, Mailbox or Character Sheet.
